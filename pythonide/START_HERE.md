# 🎯 Online Python IDE - 立即开始

**现在可以使用了!** ✅

---

## ⚡ 30 秒启动

```bash
cd pythonide
python3 -m http.server 8000
```

然后打开: **http://localhost:8000**

---

## ✅ 验证工作

1. 编辑器是否显示?
2. 输入代码: `print("Hello!")`
3. 点击 Run 按钮
4. 看到输出了吗?

## 🎓 Python 示例

```python
# 基础
print("Hello, World!")

# 变量
x = 10
y = 20
print(x + y)

# 循环
for i in range(5):
    print(i)

# 函数
def greet(name):
    return f"Hello, {name}!"

print(greet("Python"))
```
