# student-web 学生端体验增强设计

## 概述
将分散的学生功能整合到统一的个人中心仪表盘 `/center`，替换顶部导航的"我的作品"入口，提供数据概览和快捷操作。

## 路由变更

### 新增路由
- `/center` — 个人中心仪表盘（需登录）

### 路由调整
- 顶部导航"我的作品"(`/works`) → 改为"个人中心"(`/center`)
- `/works` 路由保留（可通过个人中心内的"全部作品"链接访问）
- `/home` 路由保留

### 顶部导航变更（StudentLayout.tsx）
```
旧: 社区 | 创作 | 公开课程 | 我的课程 | 我的作品 | 资讯 | 赛事
新: 社区 | 创作 | 公开课程 | 我的课程 | 个人中心 | 资讯 | 赛事
```

### 功能模块

1. **用户信息卡片**
   - 头像、昵称、签名、学校
   - "编辑资料"按钮跳转到 `/settings`

2. **数据统计行**
   - 作品数: 调用 `mineWorks({pageNo:1, pageSize:1})` 获取 total
   - 获赞数: 从 leaderboard/用户作品统计获取
   - 课程数: 调用课程 API
   - 学习天数: 从学习记录获取（如无可暂不展示）

3. **快捷创作**
   - 4 个按钮：Scratch3、Python、ScratchJr、Blockly
   - 点击打开对应 IDE

4. **最近作品**
   - 调用 `mineWorks({pageNo:1, pageSize:4})`
   - 卡片网格展示：类型图标/封面、作品名、类型标签、点赞数
   - 点击进入 `/work-detail?id=xxx`
   - "查看全部作品" → `/works`

5. **我的课程**
   - 调用课程 API 获取已加入课程
   - 列表展示：课程名、进度条、"继续学习"按钮
   - "查看全部课程" → `/home`
